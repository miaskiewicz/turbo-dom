## Replay

Use an isolated checkout of the frozen commit. No fixture/control regeneration
is necessary. Set `CARGO_TARGET_DIR` to an isolated build target:

```sh
CARGO_BUILD_JOBS=2 cargo +1.98.0 build --locked -p turbo-dom-raster --example component_parity
node tools/component-parity/run.mjs \
  --native "$CARGO_TARGET_DIR/debug/examples/component_parity" \
  --native-only --out /tmp/turbo-dom-component-final-audit
```

For offline pixel comparison, set the two local paths and run from the checkout:

```sh
export COMPONENT_AUDIT=/tmp/turbo-dom-component-final-audit
export CHROMIUM_ARCHIVE=/Users/grzegorz/github-flux/turbo-dom/.recovery-archive/triage-085-integrated-50ab
node --input-type=module <<'JS'
import {readFile} from 'node:fs/promises';
import {resolve} from 'node:path';
import {pixelDiff} from './tools/component-parity/pixels.mjs';
const {results} = JSON.parse(await readFile(resolve(process.env.COMPONENT_AUDIT, 'results.json')));
for (const row of results) {
  const stem = `${row.name}-${row.width}`;
  const chrome = await readFile(resolve(process.env.CHROMIUM_ARCHIVE, `${stem}-chromium.png`));
  const native = await readFile(resolve(process.env.COMPONENT_AUDIT, `${stem}-native.png`));
  const {changedPixels, changedFraction, meanChannelError} = pixelDiff(chrome, native);
  console.log(stem, {geometryDifferences: row.geometryDifferences, changedPixels, changedFraction, meanChannelError});
}
JS
```
